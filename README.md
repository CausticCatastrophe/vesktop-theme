# Vesktop Frosted Glass theme

A Frosted Glass theme for Vesktop with Discord's November 2026 class names.

- `build.py` assembles `dist/FrostedGlass.theme.css` and installs it into `~/.config/vesktop/themes`.
- `fg-mapped.css` is upstream Frosted Glass with the class names remapped.
- `layout-fixes.css` and `user-settings.css` are local changes and settings.
